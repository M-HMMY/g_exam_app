## 何を見るか（この順に）

### 1. ★ 答えが合っているか（最優先）

**ドリルは乱数で問題を作ります。**だから 1 回見て合っていても足りません。

- **`answer` を出す式と、`question` が言っている内容が一致しているか**
- **`choices`（誤答）の作り方に、答えと同じ値が混ざる余地がないか**
- **★ 乱数の端で壊れないか。**最小値・最大値・境目を入れて確かめること。
  **8 つめの前の代で「誤答が 0 になる」ドリルが 1 つ出ています**（丸めで 0 になる式だった）
- **単位が混ざっていないか**
- **★ 乱数の候補の直積を作って、全組合せを検算するのが確実です。**
  8 つめでは 1,092 組ありましたが、機械なら数えきれます

### 2. ★ その試験で使える電卓の制約

**試験によって違います。このアプリの受験案内書を見て、ここを書き換えてください。**

- **対数や指数を含む式を、値まで出させていないか**
- **途中の桁数が現実的か。**手で 10 桁を持ち回る問題になっていないか

### 3. 数値の出どころ

- **数値の台帳があるアプリでは、台帳を経由しているか。台帳に無い値を書いていないか**
- **物性値（比重、分子量、爆発範囲など）に一次資料が無いなら、
  決め打ちせず問題文の中で与えているか**

### 4. ウィジェット（★ ここがいちばん出ます）

- **入力の範囲。**負の数、0、極端に大きい値を入れたときに、
  **NaN・Infinity・「-0」・空文字が画面に出ないか**
- **結論が変わる境目で、表示が正しく切り替わるか**
- **★ 断定しすぎていないか。**8 つめで出た 7 件は、すべてこの型でした。

  | 出たもの | 何が問題だったか |
  | --- | --- |
  | 法令の判定 | **条文の一部の号しか見ていないのに、「当たりません」と言い切っていた** |
  | 適用除外の一覧 | **表に挙げた代表例の件数**を、法律全体の除外条数として表示していた |
  | 爆発範囲 | **下限界と上限界の中点**を「燃焼速度が最大」として表示していた。中点から求まる量ではない |
  | 理論空気量 | 炭素数と水素数を独立に選べるので、**実在しない組成**を「炭化水素」として計算できた |
  | 薄肉の応力 | 薄肉の判定が**直径基準**で、半径で見ると 20 % まで通っていた |

- **★ 値を決め打ちしていないか。**一次資料が無いものは、**ユーザーに入れさせる作り**になっているか。
  **8 つめでは、ウィジェットでユーザーに入れさせている値を、教本の本文で決め打ちしていました。**
  **アプリ自身の設計判断と食い違っていた**という形です
- **「このアプリが断定してよい範囲」を越えていないか**

### 5. 画面の文言

- **出題の実態と合っているか。**
  8 つめでは「計算問題を確実に取れるかどうかが、得点率を大きく左右します」と書いていましたが、
  **実際は学識 15 問中 4 問（機械は 1 問）**でした
- **合格基準の書き方が、その試験の公表どおりか**
- **前のアプリの試験名が残っていないか**

## 報告の形

**指摘は、次の形で 1 件ずつ書いてください。**

```
### 【重さ】 ドリル ID / ウィジェット ID — 一行の要約

- **いまの作り**：
- **何が問題か**：（★ 壊れる入力があるなら、その値を具体的に書く）
- **同じ主張のほかの居場所**：（教本・確認問題・画面の文言・執筆プロンプト）
- **正しくは**：
- **根拠**：（ファイル名と箇所、または一次資料）
```

**重さは 3 段階。**

| 重さ | 何か |
| --- | --- |
| **重** | **答えが違う。**誤答に正解と同じ値が出る／電卓で解けない／NaN が画面に出る |
| **中** | 解けるが、条件が足りず一意に決まらない。単位の書き方が紛らわしい |
| **軽** | 言い回し、桁数、配分 |

**最後に、次の 4 つを必ず書いてください。**

1. **全ドリルについて、乱数の端まで含めて答えを確かめたか**（確かめていないものは挙げる）
2. **確かめたが食い違いが無かった項目**
3. **資料からは確かめられなかった項目**
4. **★ あなたが自信を持てない指摘**

**4 が空の報告は受け付けません。**
