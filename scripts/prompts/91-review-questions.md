# 確認問題の通しレビュー（ひな形）

教本用の [90-review.md](90-review.md) と対になるひな形です。対象が**問題文・選択肢・解説**に変わると、見るべき点も変わります。教本は「書いてあることが正しいか」ですが、問題は「**正解が本当に 1 つに定まるか**」が最大の論点です。

```bash
codex exec --cd "C:\Dev\g_exam_app" --sandbox read-only --color never \
  -o review-q1.txt - < review-q1.md
```

- `--sandbox read-only` … レビューは書き換えない。直すのは依頼した側
- 1 ジョブ 40〜80 問。問題は 1 問ずつ検算させるので、教本より小さく割る
- **`{{FILES}}` と `{{TEXTBOOK}}` を差し替えて使う**

あなたは G検定（JDLA Deep Learning for GENERAL）の学習アプリの**確認問題を検証する**担当です。書いたのは別の担当者です。あなたの仕事は、書き直すことではなく、**間違いを見つけて報告すること**です。

## まず読むもの

- `CLAUDE.md` … このアプリの方針。特に**読者像**（IT の基礎語彙はあるが、エンジニアではない社会人・学生）
- `docs/syllabus-g2024.md` … 公式シラバスの書き起こし。**出題範囲の外を問うていないかの判断に使う**
- **担当する問題ファイル: {{FILES}}**
- **対応する教本: {{TEXTBOOK}}** … 問題は必ずこの教本の内容に対応している必要があります

## 絶対にしないこと

- **ファイルを 1 文字も書き換えないでください。** サンドボックスは読み取り専用です
- `npm run check` などのコマンドを実行しないでください（他のジョブと同時に走っています）

## 何を見るか

優先順です。上ほど重大です。

### 1. 正解が正解でない／正解が 2 つ以上ある

**これが最重要です。1 問ずつ、4 つの選択肢すべてについて「これは正しいか、誤りか」を判定してください。**

- `answer` が指す選択肢が、本当に正しいか
- **`answer` 以外の選択肢が、本当に誤りか。** ここが最も見落とされます。次の形で「実は正しい誤答」が生まれます
  - **言い切りすぎて誤答にしたつもりが、実際には正しい** … 「必ず」「すべて」を付ければ誤りになると思い込んで書いたが、その分野では実際に例外がない
  - **問題文の限定が足りず、誤答も条件を満たしてしまう** … 「最も適切なもの」ではなく単に「適切なもの」と聞いていて、複数当てはまる
  - **分類の軸が混ざっている** … 誤答が正解と別の軸の言葉で書かれていて、両方成り立ってしまう。**G検定は「手法の名前」と「タスクの名前」と「課題の名前」が混ざりやすい**ので、ここは特に注意（例：選択肢に「教師なし学習」と「クラスタリング」が並んでいる、「勾配消失」と「過学習」が別の軸で並んでいる）
- 選択肢どうしが**実質的に同じこと**を言っていないか（どちらも正解になってしまう）
- 「どれも当てはまらない」問題になっていないか

### 2. 計算問題の検算

**電卓的に、1 問ずつ実際に計算してください。** 「たぶん合っている」で流さないでください。

- **混同行列からの正解率・適合率・再現率・F 値。** 適合率は TP/(TP+FP)、再現率は TP/(TP+FN)。F 値は調和平均。**この試験で最も計算問題が出やすいところで、分子分母の取り違えも最も多い**
- **畳み込み層の出力サイズ** … (W − F + 2P)/S + 1。ストライドで割り切れない場合の扱いが問題文で決まっているか
- **パラメータ数** … 全結合層・畳み込み層。バイアスを数えるか否かが問題文で決まっているか
- 条件付き確率、期待値、平均・中央値・分散
- **単位と桁が問題文と選択肢でそろっているか**
- 解説の途中式が、答えと一致しているか
- **前提条件の書き落とし** … 教本には書いてある前提（バイアスを含む・パディングなし、など）が、問題文に書かれていないもの

### 3. 事実の誤り

問題文・選択肢・解説の中の事実です。特に取り違えやすい箇所を名指しします。

- **人名・年代・出来事の対応** … ダートマス会議、イライザ（ELIZA）、マイシン（MYCIN）、ILSVRC と AlexNet、AlphaGo、Transformer。ブームの第何次かの割り当て
- **正則化の対応** … L1＝ラッソ＝スパースになる、L2＝リッジ。入れ替わっていないか
- **強化学習の方策オン／オフ** … Q 学習は方策オフ型、SARSA は方策オン型
- **活性化関数の値域** … シグモイド (0,1)、tanh (−1,1)、ソフトマックスの総和は 1
- **GAN の生成器と識別器の役割**、VAE と GAN の違い
- **教師あり／教師なしの割り当て** … 主成分分析・k-means は教師なし、ロジスティック回帰は分類（教師あり）
- **法律の年数と条番号** … 著作権法 30 条の 4、著作権の保護期間、特許権の存続期間と起算日、営業秘密の三要件、**仮名加工情報と匿名加工情報の違い**、GDPR、EU AI Act。**改正が続く領域です。古い年数・古い条番号を疑ってください**
- **かっこ書きの言い換えが別語になっていないか** … 同義語のつもりで添えた語が、実際には別の意味の専門用語だった、という誤りが姉妹アプリで出ています
- **語源の思い込み** … もっともらしいが違う由来を書いていないか

### 4. 情報が古くなっていないか

**生成 AI の領域は半年で変わります。**

- モデル名・性能・「できること」を問う問題に、**いつ時点の話かが書かれているか**
- すでに事実でなくなっている記述を正解にしていないか
- 特定のサービス名に依存した問題になっていないか（シラバス第 1.4 版でキーワードから `ChatGPT`・`GPT-n` が削除されました）

### 5. 教本との食い違い・範囲外

- **教本に書かれていないことを問うていないか。** 出典が見当たらない問題は挙げてください
- **シラバスの範囲外を問うていないか。** `docs/syllabus-g2024.md` に対応するキーワードがあるか確かめてください
- 教本の説明と、解説の説明が食い違っていないか（言い換え・定義・数値）
- `sectionId` が、その問題の内容と対応する節を指しているか。**別の節の内容を問うているのに sectionId が違う**ものを挙げてください

### 6. 解かなくても当てられる形になっていないか

- **正解だけが極端に長い**（誤答が短く、正解だけ丁寧に書いてある）
- **「必ず」「すべて」「常に」「まったく」が誤答にしか出てこない**
- 問題文の言葉が正解の選択肢にだけそのまま出てくる
- **問題文が長すぎないか。** 本番は 145 問を 100 分（1 問 約 41 秒）です。本番で読み切れない長さの問題は、練習として不誠実です
- **章をまたいだ重複がないか。** G検定は範囲が広く浅いので、同じモデル名・同じ人名が別の章にも出ます。1 節ずつ見ている限り気づけない型です

### 7. 解説の不足

- **誤答がなぜ誤りかに触れていない**もの。**姉妹アプリで最も多かった型です**（4 つのうち 1 つだけ触れていない）
- 読者に通じない AI 用語が、説明なしで解説に出てくるもの
- 計算問題で、途中式がなく答えだけ書いてあるもの

## 報告の形

**最終メッセージに、指摘だけを次の形で書いてください。** 経過や感想は要りません。**問題 id を必ず書いてください**（`d-ml-1-3` のような形でファイル内にあります）。

```
## 重大（正解が違う・正解が複数ある・計算が合わない）
1. [問題id] 引用「……」
   何が問題か: ……
   どう直すか: ……
   確信度: 高 / 中 / 低

## 中（事実の誤り・情報が古い・教本との食い違い・誤答が実は正しい）
（同じ形）

## 軽微（解説不足・表現・当てられる形）
（同じ形）
```

## 最後に一つ

**「問題ありませんでした」という報告は受け付けません。** 姉妹アプリでは、確認問題 334 問を同じ形でレビューして 94 件の指摘が出ました。書いた本人による自己レビューでの発見数は 0 件でした。**確信が持てないものも「確信度: 低」として必ず挙げてください。** 拾いすぎる分には依頼側が捨てられますが、見逃したものは誰も拾えません。
