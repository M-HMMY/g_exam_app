# 教本の通しレビュー（ひな形）

書いた本人には自分の間違いが見えません。このプロンプトは、**書いた担当とは別の目**で教本を読み直させるためのものです。`{{FILES}}` を担当ファイルに差し替えて使います。

```bash
codex exec --cd "C:\Dev\g_exam_app" --sandbox read-only --color never \
  -o review-1.txt - < review-1.md
```

- `--sandbox read-only` … **レビューは書き換えない。** 指摘だけさせて、直すのは依頼した側
- 1 ジョブ 1〜2 ファイル。ファイルをまたぐ矛盾も見てほしいので、章のまとまりで割る

あなたは G検定（JDLA Deep Learning for GENERAL）の学習アプリの教本を**検証する**担当です。書いたのは別の担当者です。あなたの仕事は、書き直すことではなく、**間違いを見つけて報告すること**です。

## まず読むもの

- `CLAUDE.md` … このアプリの方針。特に**読者像**（IT の基礎語彙はあるが、エンジニアではない社会人・学生）
- `docs/syllabus-g2024.md` … 公式シラバスの書き起こし。担当ファイルが受け持つ中項目の「目標」と「キーワード」
- **担当ファイル: {{FILES}}**

## 絶対にしないこと

- **ファイルを 1 文字も書き換えないでください。** サンドボックスは読み取り専用です
- `npm run check` などのコマンドを実行しないでください（他のジョブと同時に走っています）

## 何を見るか

優先順です。上ほど重大です。

### 1. 事実の誤り

G検定の出題範囲として**間違っている記述**を探してください。あなたの知識と照らして、少しでも怪しいと思ったら挙げてください。「たぶん合っている」で流さないでください。

**特に間違いが多い箇所を名指しします。ここは 1 つずつ確かめてください。**

- **人名・年代・出来事の対応** … ダートマス会議（1956 年、「人工知能」という語の初出）、イライザ（ELIZA）、マイシン（MYCIN）と DENDRAL の対象領域の違い、Cyc プロジェクト、東ロボくん、ワトソン、ネオコグニトロン、ILSVRC で AlexNet が勝った年、AlphaGo、Transformer の発表年。**「第 1 次／第 2 次／第 3 次ブームのどれか」の割り当ても取り違えやすい箇所です**
- **評価指標の分子と分母** … 適合率は TP/(TP+FP)、再現率は TP/(TP+FN)。**この 2 つの取り違えは定番の誤りです。** F 値は調和平均であって相加平均ではない。混同行列の 4 マスの並びが本文と表で一致しているか
- **活性化関数の値域と性質** … シグモイドは (0,1) で微分の最大値は 0.25、tanh は (−1,1) で微分の最大値は 1、ReLU は max(0, x)、ソフトマックスの出力は総和が 1。**勾配消失問題の説明が「0.25 を掛け続けるから」と整合しているか**
- **正則化の対応** … L1 正則化＝ラッソ回帰＝パラメータが 0 になりやすい（スパース）、L2 正則化＝リッジ回帰＝0 に近づくが 0 にはなりにくい。**入れ替わっていないか**
- **強化学習の方策オン／オフ** … Q 学習は方策オフ型、SARSA は方策オン型。**取り違えやすい箇所です**
- **教師あり／教師なしの割り当て** … 主成分分析・k-means・t-SNE・トピックモデルは教師なし。ロジスティック回帰は名前に反して分類。サポートベクターマシン・決定木・ランダムフォレストは教師あり
- **バギングとブースティングの違い** … 並列か逐次か、ランダムフォレストがどちらに属するか
- **GAN の 2 つのネットワークの役割** … 生成器（ジェネレータ）が偽物を作り、識別器（ディスクリミネータ）が本物か偽物かを見分ける。**どちらがどちらか入れ替わっていないか**
- **畳み込みの出力サイズとパラメータ数** … 出力サイズは (W − F + 2P)/S + 1。**本文の数値例を実際に計算して検算してください**
- **エポック・イテレーション・バッチサイズの関係** … 数値例が矛盾していないか
- **法律の年数と条番号** … 著作権法 30 条の 4（情報解析のための利用）、著作権の保護期間、特許権の存続期間と起算日、営業秘密の三要件、個人情報保護法における**仮名加工情報と匿名加工情報の違い**、GDPR、EU AI Act の適用時期。**改正が続く領域なので、古い年数・古い条番号が書かれていないか特に注意**
- **ガイドラインの名称と発行主体** … AI 事業者ガイドライン、カメラ画像利活用ガイドブック、AI・データの利用に関する契約ガイドライン

### 2. 情報が古くなっていないか（このアプリ固有の観点）

**生成 AI の領域は半年で変わります。** 姉妹アプリにはなかった問題です。

- **モデル名・性能・「できること」の記述に、いつ時点の話かが書かれているか。** 書かれていなければ、それ自体を指摘してください
- 「最新の」「現在最も高性能な」のような、時点を書かずに最上級を使っている記述
- すでに事実でなくなっている記述（当時の性能上限、当時できなかったこと）
- **公式シラバス第 1.4 版（2026 年 5 月 11 日）で、キーワードから `ChatGPT` と `GPT-n` が削除されました。** 個別のサービス名に依存した説明になっていないか

### 3. 読者に通じない書き方

**事実として正しくても、AI の用語を説明なしで使っていれば失格です。**

読者像を取り違えないでください。**「サーバ」「データベース」「アルゴリズム」は説明なしで通じます。**通じないのは「勾配」「尤度」「正則化」「分散表現」といった AI・機械学習の語です。

- **初出の AI 用語が、その場で言い換えられていないもの**を挙げてください。「後で説明します」は方針違反です
- **数式に「読み方」が添えられていないところ。** この教本は数式を出しますが、**解かせません。変形もさせません。** シグマが出たら「全部足す、という意味」と書く方針です。読者に式変形を求めている箇所があれば挙げてください
- **人名・モデル名が「それが何を変えたか」なしに並んでいるところ。** 名前の羅列は覚えられません
- 抽象的な定義がたとえ話より先に来ていて、読み進められないところ
- カタカナ語に「なぜその名前なのか」が添えられていないもの

### 4. 節をまたいだ矛盾・重複

- 同じ用語を、節によって違う意味・違う言い換えで説明していないか
- 同じ数値・同じ例が、別の節で違う値になっていないか
- **本文と図の食い違い**（図の軸・向き・要素数が本文と違う）
- **例と一般論の食い違い**（直前の具体例と、一般化した説明の数が合っていない）
- 「◯◯で説明したとおり」と書いてあるのに、そこに書かれていないもの

### 5. 記法の崩れ

本文は Markdown サブセットです。`src/lib/digest.ts` が「# この節のまとめ」「> **試験のポイント**」「> **よくある勘違い**」を機械的に抜き出して直前チェックシートを作るので、**書式が崩れると拾われません。**

- 節の骨格（`# ざっくり言うと` → 本論 → `# この節のまとめ` → ` ```quiz `）が崩れていないか
- 表の列数がそろっているか
- ` ```diagram:compare ` の要素が偶数個か（1 行 1 セル、偶数行が左・奇数行が右）
- 図の中に `**強調**` を書いていないか（効きません）
- `[文字](textbook/xxx)` のリンク先が実在する節 id か。実在する id は次で全部です：
  {{SECTION_IDS}}
- ` ```quiz ` の中が `問い :: 答え` の形になっているか
- **一問一答が薄くないか。** 本番は 145 問を 100 分（1 問 約 41 秒）で解く試験なので、一問一答がそのまま速度対策になります。1 節 5 問未満なら指摘してください

## 報告の形

**最終メッセージに、指摘だけを次の形で書いてください。** 経過や感想は要りません。

```
## 重大（事実として間違っている）
1. [ファイル名 / 節id] 引用「……」
   何が問題か: ……
   どう直すか: ……
   確信度: 高 / 中 / 低

## 中（誤解を招く・情報が古い・読者に通じない）
（同じ形）

## 軽微（記法・表現）
（同じ形）
```

## 最後に一つ

**「事実に自信がない箇所はありませんでした」という報告は受け付けません。** 姉妹アプリで同じ形のレビューをしたとき、教本 52 節から 90 件超（重大な事実誤り 30 件）が見つかりました。自己レビューでの発見数は 0 件でした。見つからなかったのなら、それは読み方が浅いということです。**確信が持てないものも「確信度: 低」として必ず挙げてください。** 拾いすぎる分には依頼側が捨てられますが、見逃したものは誰も拾えません。
