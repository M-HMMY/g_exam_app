# G検定 学習アプリ

G検定（JDLA Deep Learning for GENERAL）の学習アプリです。**教本（通読できる読み物）を軸に**、確認問題、間隔反復による復習、直前チェックシート、模試、成績分析までを 1 つにまとめてあります。学習記録はブラウザの localStorage にのみ保存され、**外部には一切送信されません。**

`fe_exam_app`（基本情報技術者試験）→ `e_exam_app`（E資格）→ `itpassport_exam_app`（ITパスポート）と引き継いできた土台の上に作られています。画面の作り・記法・運用の作法はそれらと共通です。

> **現状** 教本は全 13 章 59 節（約 28 万字）、確認問題は 435 問まで書けています。**確認問題はまだ別の目でのレビューを通していません。**計算ドリルと一部の体験ウィジェットは未着手です。書き方は [CLAUDE.md](CLAUDE.md) を参照してください。

## 想定する読者

G検定には受験資格がなく、実際に受けるのは事業部門の社会人、企画職、学生など、**IT の基礎語彙はあるがエンジニアではない人**です。教本はその前提で書いています。

- 「サーバ」「データベース」は説明なしで使う
- 「勾配」「尤度」は、初めて出したその場で必ず言い換える
- **数式は出すが、解かせない・変形させない。**「読み方」だけを添える

## この試験の特徴

| 項目 | 内容 |
| --- | --- |
| 形式 | 多肢選択式のみ。記述も実技もない |
| 出題数 | **145 問程度** |
| 試験時間 | **オンライン 100 分 / 会場 120 分**（同じ問題数で時間が違う） |
| 実施 | オンライン 年 6 回 / 会場 年 3 回 |
| 受験資格 | なし |
| 合格基準 | **非公表** |
| シラバス | G2024（第 1.4 版）。書き起こしが [docs/syllabus-g2024.md](docs/syllabus-g2024.md) にあります |

**1 問あたり約 41 秒しかありません。**考えて解く試験ではなく、用語を即座に思い出せるかの試験です。そのためこのアプリでは、一問一答と直前チェックシート、全文検索を厚くしてあります。

**合格基準が非公表なので、このアプリは合否を判定しません。**模試の結果画面が出すのは、正答率・**時間内に解き切れたか**・分野別と章別の正答率の 3 つだけです。点数への換算も「合格圏」といった表示もしません。模試の構成比はシラバスのキーワード数から按分した推定値で、**本番の内訳ではありません**（JDLA は公表していません）。

要項もシラバスも改訂されます。申し込みの前に [JDLA の公式サイト](https://www.jdla.org/certificate/general/) で最新の情報を確認してください。

## 起動

```
npm install     # 初回のみ
npm run dev     # http://localhost:5173 が開く（開発用・自動リロードあり）
npm run build   # 本番ビルド（出力は dist/）
npm run preview # http://localhost:4173 でビルド済みのものを配信
npm run check   # データの整合性チェック（教本・問題・ドリル・描画）
```

Windows では `launch.cmd`（開発サーバ）をダブルクリックしても起動できます。ビルド済みのものを配信するランチャは `scripts/launch.cmd` で、こちらはデスクトップのショートカットから呼ぶことを想定しています。

アイコンは `python scripts/make_icons.py` で作り直せます（外部ライブラリ不要）。PWA 用の `public/icons/` とショートカット用の `scripts/app.ico` の両方を書き出します。

## iPhone / Android で使う

PWA なので、**ホーム画面に追加するとアドレスバーのないアプリとして起動**し、一度開いたページはオフラインでも読めます。教本 28 万字を電車の中で読むのが主な使い道です。

**iPhone（Safari で開くこと。Chrome や他のブラウザからは追加できません）**

1. 公開 URL を **Safari** で開く
2. 画面下部の共有ボタン（□に↑）をタップ
3. メニューを下へたどって「**ホーム画面に追加**」
4. 名前が「G検定」になっていることを確認して「追加」

**Android** … Chrome のメニューから「アプリをインストール」または「ホーム画面に追加」。

### 知っておくとよいこと

- **オフライン保存（Service Worker）は HTTPS でのみ有効です。**同じ Wi-Fi 内で `http://192.168.x.x:5173` を開く方法でも閲覧はできますが、オフライン保存は効かず、PC 側でサーバを動かしておく必要があります
- **学習記録は端末ごとです。** PC とスマートフォンでは共有されません。設定画面のエクスポート／インポートで移せます
- ホーム画面のアイコンを削除すると、その端末の学習記録も消えます。区切りのよいところでエクスポートしておくと安全です

## GitHub Pages へ公開する

[.github/workflows/deploy.yml](.github/workflows/deploy.yml) を用意してあります。**`main` ブランチへ push するたびに**自動でビルドして公開されます。

初回だけ次の手順が必要です。

```powershell
git remote add origin https://github.com/<ユーザ名>/<リポジトリ名>.git
git push -u origin main
```

その後、GitHub のリポジトリで **Settings → Pages → Build and deployment → Source** を **GitHub Actions** に変更します。数分後に `https://<ユーザ名>.github.io/<リポジトリ名>/` で公開されます。

`vite.config.ts` の `base` は `'./'`（相対パス）で、ルータもハッシュ方式なので、**リポジトリ名がどうであってもサブディレクトリ配信で正しく動きます。**

公開リポジトリにするので、**コミットの署名には GitHub の noreply アドレスを使ってください**（実メールアドレスは履歴に永久に残ります）。

## 画面

| 画面 | 内容 |
| --- | --- |
| ホーム | 進捗、試験日カウントダウン、1 日のノルマ、弱点分野、「もう一度読みたい節」 |
| 教本 | 章順に読む本編（13 章 59 節）。全文検索・栞・理解度 3 段階の記録つき |
| 体験ツール | 対話ウィジェットの一覧（`src/components/widgets/` にファイルを置くと自動で有効になる） |
| 確認問題 | 四肢択一 435 問。章別／出題数指定／誤答優先。1 問ごとに解説と教本への導線 |
| 計算ドリル | 出題のたびに数値が変わる自動生成問題。**本番は 1 問 41 秒なので主役ではありません** |
| 直前チェック | 全 59 節の「まとめ」「試験のポイント」「よくある勘違い」を抜き出した一覧 |
| 復習 | SM-2 を簡略化した間隔反復。誤答は自動的にここへ回る |
| 模試 | 本番と同じ問題数・時間制限つきの通し演習。**合否は判定しない**（上記） |
| 成績分析 | 分野別の正答率、日別の推移、模試の履歴 |
| 設定 | 試験日、テーマ、学習記録のエクスポート／インポート |

## 技術的な前提

- React 18 + Vite 5 + TypeScript（strict、未使用変数もエラー）
- **ランタイム依存は React だけ。** ルータも Markdown も数式も図も自前で、**外部通信は一切しない**
- 学習記録は localStorage のみ。サーバもアカウントもない
- Service Worker によるオフライン対応（HTTPS でのみ有効）

## 内容の正しさについて

このアプリの教本と問題は生成 AI で書いています。**書いた本人が読み返しても誤りは見つからない**ことが系譜を通じて分かっているため、**別の目で通しレビューする工程**を必ず入れています。教本は全 13 章について 2 回に分けてレビューし、200 件を超える指摘のうち採用分を反映済みです。**確認問題 435 問はまだレビュー前です。**

それでも誤りは残り得ます。**特に法律・ガイドラインの年数と条番号、生成 AI 分野の「いま」の記述**は、一次資料で確かめてください。教本の中でも「いつ時点の話か」を本文に書くようにしています。
